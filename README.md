# Доктор Кудрявцева — сайт стоматологической практики

Статический многостраничный сайт (HTML + CSS + JS) с одной серверной функцией Vercel для приёма заявок.
Рабочая версия: https://dr-kudryavceva.online — обновляется автоматически при пуше в `main`.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `services.html`, `services/*.html` | Услуги и 6 подробных страниц |
| `about.html` | О докторе |
| `cases.html` | Примеры работ (галерея клинических случаев) |
| `contacts.html` | Контакты и запись |
| `privacy.html`, `consent.html` | Политика конфиденциальности и согласие на обработку данных |
| `404.html` | Страница ошибки |
| `api/booking.js` | Приём заявок с формы → Telegram |

## 1. Онлайн-запись → WhatsApp

Форма записи (имя, услуга, комментарий) открывает WhatsApp доктора по ссылке `whatsapp` из `assets/js/config.js`.
Ссылка вида `wa.me/message/…` не принимает готовый текст, поэтому текст заявки копируется в буфер обмена —
пациент вставляет его в чат. Если указать `waNumber` (только цифры, 79001234567), текст подставится в чат сам;
сам номер на сайте не показывается, но виден в адресе ссылки.

`api/booking.js` (отправка заявок в Telegram-бота) сейчас не используется.

## 2. Контакты и реквизиты — `assets/js/config.js`

Телефон, Telegram, WhatsApp, e-mail, адрес, часы приёма, ссылка на карту, а также реквизиты оператора
персональных данных и лицензия. Пустые поля на сайте не показываются.

## 3. Клинические случаи — `assets/js/cases.js`

1. Положите оригинальные фото в `assets/img/cases/` (без ретуши, .webp/.jpg шириной 1200–1600 px).
2. Добавьте случай в `window.CASES` (пример внутри файла).
3. `order: "unknown"` — фото показываются как этапы лечения, без подписей «до/после».
   После подтверждения доктором поставьте `order: "confirmed"`, `before` и `after` — появится слайдер сравнения.

Пока случаев нет, блок на главной скрыт, а на странице «Примеры работ» предлагается запись на консультацию.

## 4. Тексты, квалификация, фото услуг — `src/content.mjs`

- `ABOUT` — образование, опыт, курсы, сертификаты. Блок «Образование и опыт» появится на странице «О докторе», только когда списки заполнены.
- `DOCS` — дипломы и сертификаты (блок «Дипломы и сертификаты» на странице «О докторе», клик — просмотр в полном размере).
  Файлы лежат в `assets/img/docs/`: `<имя>.webp` (2400 px по длинной стороне) и `<имя>-720.webp` (превью).
  У многостраничного документа несколько файлов в `files` — они листаются в просмотре.
- `image` у услуги — фото для карточки (пока показывается иконка).

После правок в `src/` пересоберите страницы:

```bash
node src/build.mjs
```

Нужен Node.js 18+. При смене домена поменяйте `SITE_URL` в `src/build.mjs` (canonical, sitemap, og:image).

## 5. SEO — `src/build.mjs`, блок «SEO-настройки»

- `CITY`, `CITY_IN`, `REGION` — город приёма: попадает в title, description, H1 услуг и разметку Schema.org.
- `YANDEX_VERIFICATION`, `GOOGLE_VERIFICATION` — коды подтверждения из Яндекс Вебмастера и Google Search Console (только значение `content`).
- `YANDEX_METRIKA_ID` — номер счётчика Метрики; пусто — счётчик не подключается.
- `SAME_AS` — ссылки на профили врача (Яндекс Карты, ПроДокторов, НаПоправку, Telegram) для разметки.
- SEO-заголовки и FAQ услуг — поля `seoTitle`, `h1`, `seo`, `faq` в `src/content.mjs`.
- `favicon.ico`, `icon-*.png`, `apple-touch-icon.png`, `assets/img/og-image.jpg` (превью ссылок 1200×630) — готовые файлы.
- Адрес `dr-kudryavceva.vercel.app` перенаправляется на основной домен (`vercel.json`), чтобы не было дублей.
