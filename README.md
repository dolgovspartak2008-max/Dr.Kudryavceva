# Доктор Кудрявцева — сайт стоматологической практики

Статический многостраничный сайт (HTML + CSS + JS) с одной серверной функцией Vercel для приёма заявок.
Рабочая версия: https://dr-kudryavceva.vercel.app — обновляется автоматически при пуше в `main`.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `services.html`, `services/*.html` | Услуги и 6 подробных страниц |
| `about.html` | О докторе |
| `cases.html` | Примеры работ (галерея клинических случаев) |
| `contacts.html` | Контакты и запись |
| `privacy.html`, `consent.html` | Политика конфиденциальности и согласие на обработку данных |
| `404.html` | Страница ошибки |
| `api/booking.js` | Приём заявок с формы → Telegram |

## 1. Включить онлайн-запись (Telegram)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите боту любое сообщение (или добавьте его в группу/канал) и узнайте `chat_id`
   (например, через `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. Vercel → проект `dr-kudryavceva` → Settings → Environment Variables:
   - `TELEGRAM_BOT_TOKEN` — токен;
   - `TELEGRAM_CHAT_ID` — id чата (несколько — через запятую);
   - необязательно `BOOKING_WEBHOOK_URL` — дополнительная отправка в CRM/Make/n8n.
4. Сделайте Redeploy.

Пока переменные не заданы, форма проверяет данные, но **честно сообщает, что заявка не отправлена**,
и предлагает связаться по телефону или в мессенджерах (если они указаны).

## 2. Контакты и реквизиты — `assets/js/config.js`

Телефон, Telegram, WhatsApp, e-mail, адрес, часы приёма, ссылка на карту, а также реквизиты оператора
персональных данных и лицензия. Пустые поля на сайте не показываются.

## 3. Клинические случаи — `assets/js/cases.js`

1. Положите оригинальные фото в `assets/img/cases/` (без ретуши, .webp/.jpg шириной 1200–1600 px).
2. Добавьте случай в `window.CASES` (пример внутри файла).
3. `order: "unknown"` — фото показываются как этапы лечения, без подписей «до/после».
   После подтверждения доктором поставьте `order: "confirmed"`, `before` и `after` — появится слайдер сравнения.

Пока случаев нет, блок на главной скрыт, а на странице «Примеры работ» предлагается запись на консультацию.

## 4. Тексты, квалификация, фото услуг — `src/content.mjs`

- `ABOUT` — образование, опыт, курсы, сертификаты. Блок «Образование и опыт» появится на странице «О докторе», только когда списки заполнены.
- `image` у услуги — фото для карточки (пока показывается иконка).

После правок в `src/` пересоберите страницы:

```bash
node src/build.mjs
```

Нужен Node.js 18+. При смене домена поменяйте `SITE_URL` в `src/build.mjs` (canonical, sitemap, og:image).
