# Доктор Кудрявцева — сайт стоматологической практики

Статический многостраничный сайт без зависимостей: HTML + CSS + JS. Работает на любом хостинге (GitHub Pages, Netlify, Vercel, обычный хостинг).

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `services.html` | Все услуги |
| `services/*.html` | Подробные страницы 6 услуг |
| `about.html` | О докторе |
| `cases.html` | Примеры работ «До / После» |
| `contacts.html` | Контакты и запись |
| `privacy.html` | Политика обработки персональных данных (заготовка) |
| `404.html` | Страница ошибки |

## Что заполнить перед запуском

### 1. Контакты и отправка формы — `assets/js/config.js`
Телефон, Telegram, WhatsApp, адрес, часы приёма, ссылка на карту.
Пустые поля на сайте не показываются (в шапке) или выводятся как «будет добавлено» (на странице контактов).
`formEndpoint` — адрес обработчика заявок (принимает POST JSON `{ name, phone, service, comment, page }`).
Пока он пуст, форма проверяет данные, но ничего не отправляет.

### 2. Клинические случаи — `assets/js/cases.js`
1. Положите оригинальные фото в `assets/img/cases/` (без ретуши, желательно .webp/.jpg шириной 1200–1600 px).
2. Добавьте случай в массив `window.CASES` (пример внутри файла).
3. Поле `order`:
   - `"confirmed"` — доктор подтвердил: первое фото = ДО, второе = ПОСЛЕ. Показывается слайдер сравнения.
   - `"unknown"` — порядок не подтверждён. Фото показываются без подписей «до/после», с пометкой «порядок уточняется».

Категории: `restavraciya`, `perelechivanie`, `protezirovanie`, `implantaciya`, `kostnaya-plastika`, `udalenie`.

### 3. Тексты-заготовки
Образование, опыт, повышение квалификации, сертификаты (`about.html`), цены на страницах услуг и текст политики
отмечены пунктирными блоками «Для заполнения». Тексты правятся в `src/build.mjs` и `src/content.mjs`.

### 4. Домен и SEO
Укажите адрес сайта в `SITE_URL` в `src/build.mjs` и пересоберите — появятся canonical-ссылки, og:image и `sitemap.xml`.

## Сборка

Страницы генерируются из шаблонов (общие шапка, подвал, иконки, форма):

```bash
node src/build.mjs
```

Нужен Node.js 18+. После сборки HTML-файлы в корне обновляются.

## Публикация на GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)`.
